# RecruiterFlow Full Stack Internship Assignment

This repository contains my complete submission for the Full Stack Developer Intern take-home assignment. The project is divided into three distinct, self-contained sections as requested.

## Project Structure
*   **`/backend`**: Section B (Build-a-Recruiter-Bot & SQL Detective). Python 3, FastAPI, Uvicorn, and Python's built-in `sqlite3` (raw SQL without ORM), featuring an isolated candidate-matching algorithm and Pytest test suite.
*   **`/frontend`**: Section C (Trip Splitter). React 18, Redux Toolkit, Vite, and strict TypeScript with a pure vanilla CSS design system (no UI libraries, mobile-responsive down to 360px), and Vitest unit testing.
*   **`/qa`**: Section A (QA Automation). Playwright with TypeScript configured strictly for Chromium, featuring the Page Object Model (POM) pattern for SauceDemo UI testing and API testing against ReqRes.

Each directory contains its own `README.md` with specific installation and execution instructions.
